# Crediti delle immagini

Fonte, licenza e autore delle immagini storiche del gioco. Tutte vengono da Wikimedia Commons.

- `foto-alleati.md`, `foto-nazisti.md`, `foto-comunisti.md`, `foto-nipponici.md`: le foto delle unità (`client/src/assets/units/`), una dottrina per file.
- `ritratti-capi-di-stato.tsv`: i ritratti dei capi delle nazioni (`client/src/assets/leaders/`), con la licenza letta da Wikimedia Commons il 3 novembre 2026.

Le immagini con licenza **CC BY-SA** (per esempio quelle del Bundesarchiv e dell'archivio RIA Novosti) si possono usare e modificare citando la fonte, e anche le versioni ritagliate restano CC BY-SA. Quelle **CC BY** chiedono solo di citare l'autore. Le altre sono di pubblico dominio o CC0.
